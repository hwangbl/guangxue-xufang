本实验使用理想暗环中心线读数。请在测量时保持光路、调焦和支架位置不变。三位小数表示估读，不代表实物分度达到 0.001 mm。

操作指南

完成一次牛顿环测量

  1. 打开钠灯，将半反镜设为倾角 45°、方位 0°，前方水平光向下反射。
  2. 调焦至条纹清晰，目镜视度调至叉丝清晰。纵丝应垂直于测量方向。
  3. 选择暗环级次。先在环心数清环次，再移动鼓轮，使纵丝与该暗环的左侧中心线相切并记录；继续移动到右侧记录。
  4. 重复测量另一环次。选择 m、n，计算曲率半径；可导出记录。

鼠标拖动背景转动仪器，滚轮缩放。点击旋钮可选中，沿上下方向拖动调节，也可使用数值控件。测量位置支持键盘左右键细调，Shift + 左右键粗调。

理想条纹公式：rk² = kλR。暗环中心是第 0 级，从中心向外数。对于本页未倒像的物平面视野，位置读数增大时视野图样向右平移。
